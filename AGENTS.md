## North Star

**AIGRO** (AI + Growth) — 香港最值得信賴的 AI・增長・商業情報平台：trusted
AI/growth/business intelligence for Hong Kong, evolving toward a knowledge
marketplace (Verified expert AI avatars → human bookings → open MCP/API).

- **Live URL**: https://aigro-blue.vercel.app (alias)
- **Repo**: github.com/ekcheungAI/aigro
- **Deploy target**: Vercel, project `aigro`, alias `aigro-blue.vercel.app`.
  Push to `main` → CI verifies → **`.github/workflows/deploy.yml` deploys on
  success only**. A failing verify means no deploy; the live site keeps the
  last good build. Requires `VERCEL_TOKEN` / `VERCEL_ORG_ID` /
  `VERCEL_PROJECT_ID` as repo secrets — see `docs/DEPLOY-SETUP.md`. To
  re-deploy the current `main` without a code change, use **Run workflow** on
  the deploy action rather than an empty commit.

| `npm run fetch:aihot` | Refresh AIHOT data snapshot (see Data Flow) |

**AIHOT fetch note**: the upstream API at `https://aihot.virxact.com` is public and
keyless, but it **blocks browser User-Agents** — the fetch script must keep its custom
UA (`aihot-skill/...` in `scripts/fetch-aihot.mjs`). Do not hammer it; refresh sparingly.

## Hard Rules (brand — condensed from docs/design-system.md + docs/taste-rules.md)

Violating these is a bug. When in doubt, read `docs/design-system.md`.

### Color / tokens
- **CSS variables only — never hardcode hex** in components. Tokens live in
  `src/index.css` (`:root` + `.dark`) as HSL triplets, mapped through `tailwind.config`.
- **Black + lime is the brand**: electric lime `#43F50E` is the *only* accent.
  On light mode, text/links use deep green `#1F7A06` (`lime-text`, AA on paper);
  interactive fills are pure lime + near-black text (`on-accent` `#0D0D0C`, black on green).
- **Gold is retired → lime.** Legacy token names (`--ink*`, `--gold*`) exist only as
  aliases into the lime system. Never add new ink/gold colors.
- **No decorative gradients** — backgrounds, buttons, cards are flat solids. Only
  exception: hard-stop stripe/chevron patterns (`.stripe-block`, `.stripe-block-dark`,
  `.chevron-strip`; max ~3 stripe moments per page; never hand-roll new patterns).
- Lime is for accent only — never a large-area background.
- **Hairlines over shadows**: 1px borders first; dark mode uses borders only, no shadows.

### Typography
- Traditional Chinese brand voice: **Chiron GoRound TC** across display, body/UI,
  and CJK fallback for data/mono. Latin remains **Fraunces** (display), **Inter**
  (body/UI), and **IBM Plex Mono** (data), via
  `--font-cjk/--font-display/--font-sans/--font-mono`.
- Latin headlines use Fraunces; Chinese headlines and UI use Chiron. CJK body text
  ≥ 13px; article max-width 44rem.

### Voice / copy
- UI language is **繁體中文（香港用語）+ 書面粵語** where conversational (e.g. Ask,
  waitlist forms). Nav/product labels are bilingual (`Insights 情報`, `Ask 問答`).
- **No emoji in visible UI strings.** Upstream feed data is sanitized in the data layer.

### Motion (docs/taste-rules.md is the authority)
- `--ease-out-strong: cubic-bezier(0.23,1,0.32,1)` for hover/press/micro-interactions
  (JS twin `EASE_OUT_STRONG` from `src/components/Reveal.tsx`). Never `ease-in` on UI.
- UI transitions **≤ 300ms** (press 160ms, chips 120–180ms, drawers ≤ 500ms).
- Press feedback: `.press` utility → `scale(0.97)`, 160ms, on every button/chip.
- **Hover gating**: transform-based hovers only inside
  `@media (hover: hover) and (pointer: fine)` — use `.card-hover`, `.nudge-x`, etc.;
  do not use Tailwind `hover:-translate-*` for motion.
- **Reduced motion**: transforms off, gentle opacity fades stay; all keyframes gated
  behind `prefers-reduced-motion: no-preference`.
- Framer Motion hot paths: use full `transform:` strings, not `x:/y:/scale:` shorthands.
- Icons: lucide-react only, `strokeWidth={1.5}`.

### Theme
- Class-based dark mode (`.dark` on `<html>`), localStorage-persisted, system default.
- **Dark mode parity is required** — both themes individually tuned, never an afterthought.

## Data Flow (AIHOT)

```
AIHOT public API (https://aihot.virxact.com/api/public, no key, custom UA required)
  → scripts/fetch-aihot.mjs   (node; OpenCC cn→hk 繁體香港 + emoji strip at write time)
  → src/data/aihot-snapshot.json   (committed snapshot; build is self-contained)
  → src/data/aihot.ts         (typed loaders; runtime only strips stray emoji via clean())
  → UI (Insights feed, Daily 日報, HotTopicsTicker, LiveStats)
```

- **Attribution is required**: rendered AIHOT content must keep source attribution
  and canonical links (see `AihotAttribution` in `src/data/aihot.ts`).
- `opencc-js` is a **devDependency** for the fetch script only — never import it at runtime.
- To refresh data: `npm run fetch:aihot`, then commit the updated snapshot.

## Conventions

- Pages: `src/pages/*.tsx`, **default export**, one component per route.
- Data: typed modules in `src/data/` (no ad-hoc fetch in components; frontend is
  currently mock/snapshot-driven, no backend).
- Scroll animation: wrap sections in `<Reveal>` (do not hand-roll IntersectionObservers).
- Motion/quality passes must not change layout, colors, copy, or the token set
  (taste-rules §10).
- Consult `docs/taste-rules.md` before any animation work; `docs/design-system.md`
  before any visual work.

## Gotchas

- **`vite.config.ts` `base` must stay `'/'`** — Vercel serves from root.
- **`package-lock.json` must resolve to `registry.npmjs.org`** (no mirror URLs), or
  Vercel installs fail.
- **SPA rewrites in `vercel.json` are required**
  (`{"rewrites":[{"source":"/(.*)","destination":"/index.html"}]}`) — deep links 404 without it.
- Dev server port is fixed at 3000.
- `plugin-inspect-react-code` (`inspectAttr`) is enabled in vite config — leave it in place.
